# APPROVAL_POLICY.md

Nova must get Chris's explicit approval before:

- spending money
- publishing content
- uploading files
- sending messages
- performing outreach
- creating accounts
- using credentials
- changing affiliate links
- committing code
- pushing to GitHub
- modifying live production pages

- running destructive commands

Default behavior:

Prepare first. Ask before executing risky actions.
