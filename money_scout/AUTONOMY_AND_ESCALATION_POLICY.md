# Autonomy and Escalation Policy

## Local AI Can Do Without Asking

- read local reports
- scan approved feeds
- dedupe ideas
- score ideas
- park weak ideas
- create local artifacts
- create local reports
- run enterprise audits
- summarize findings
- recommend next actions
- use Opportunity Index to choose where to work harder locally

## Large AI Proxy Can Decide

- which source-review idea looks strongest
- which local artifact needs improvement
- which weak idea should stay parked
- which scoring rule needs tightening
- what local-only priority should happen next

## Chris Required

Chris must approve:

- publishing
- selling
- outreach
- sending messages
- committing code
- pushing to GitHub
- spending money
- creating accounts
- using credentials
- changing affiliate links
- changing live production pages
- claiming legal/compliance certainty
- increasing any budget cap

## Stop Conditions

Stop and escalate if:

- enterprise audit fails
- JSON corruption appears
- gateway/task health fails
- evidence conflicts
- the same error repeats across cycles
- a script attempts external action without approval
- a task requires credentials or spending
