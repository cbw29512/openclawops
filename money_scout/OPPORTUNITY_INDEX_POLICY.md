# Opportunity Index Policy

## Purpose

The Opportunity Index lets Chris steer Nova Money Scout with simple positive or negative signals.

Approve / Boost means:
- increase priority_index by 1
- allow more local research
- allow artifact improvement
- allow better angle discovery
- allow local-only review packet creation

Disapprove / Bury means:
- decrease priority_index by 1
- park or reduce effort
- preserve idea for dedupe memory
- allow revival only if new evidence, a new angle, or Chris votes bring it back

## Safety

Approve does not mean:
- publish
- sell
- outreach
- send messages
- commit
- push
- spend money
- create accounts
- use credentials
- change live pages
- change affiliate links
- claim legal/compliance certainty

External actions require explicit Chris approval.
