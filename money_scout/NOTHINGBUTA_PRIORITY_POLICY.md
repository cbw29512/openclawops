# NothingButA Priority Policy

Created: 2026-05-20T08:27:17-04:00

## Priority

Nova/OpenClaw Money Scout should treat the NothingButA Quality Utility Network as the active priority lane.

## Objective

Build one high-quality single-purpose SEO utility website/tool at a time.

The goal is durable organic growth, not fast money and not mass website generation.

## Core Rule

Nova may research many ideas, but only one active build candidate is allowed at a time.

## Quality Direction

Each tool should be treated as a small software product.

A valid tool must:

- solve one clear user problem
- work locally before publishing
- be mobile-first
- be fast
- have clean code
- include useful examples
- include helpful plain-English explanation
- avoid copied competitor content
- avoid thin SEO pages
- avoid doorway-page behavior
- include a local audit before Chris reviews it

## Safety Gates

Nova must not do any of the following without Chris approval:

- publish a website
- buy a domain
- connect ads
- add affiliate links
- collect leads or emails
- send outreach
- commit or push code
- spend money
- create accounts
- use credentials
- claim guaranteed rankings or income

## First Build Guidance

Magic 8 Ball was a nostalgic example, not the serious first target.

The first serious candidate should likely come from:

1. Debt payoff calculator
2. Budget calculator
3. Invoice generator
4. QR code generator
5. Tip calculator

Nova should score candidates based on:

- usefulness
- search intent
- build difficulty
- monetization fit later
- SEO competitiveness
- trust/safety risk
- ability to improve weekly

## State Flow

research_only
→ definition_of_done_locked
→ first_tool_candidate_selected
→ local_mockup_ready
→ local_quality_audit
→ local_seo_audit
→ chris_review_required
→ approved_to_publish
→ published
→ baseline_tracking
→ weekly_optimization
→ next_tool_candidate

## Long-Game Principle

This lane should compound through quality, maintenance, analytics, and weekly improvements.

Nova should improve the current tool before chasing the next shiny idea.
